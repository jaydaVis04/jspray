# Maintenance policy

JAYSPRAY is an owner-maintained project. The upstream repository does not accept external
code contributions, pull requests, feature requests, support requests, or requests for
collaborator access. Unsolicited pull requests may be closed without review.

GitHub pull-request creation is restricted to repository collaborators, and the owner is the
only collaborator. Issues, discussions, projects, and the wiki are disabled.

The public repository is provided so people can clone and use JAYSPRAY under the terms of
the [MIT license](LICENSE). The license also governs copies and forks; it does not grant
permission to push to or merge changes into the upstream repository.

The owner maintains `main` through protected, CI-checked maintenance changes. Automated
dependency-update pull requests are intentionally disabled. Dependencies are reviewed and
updated as part of owner maintenance.

Security vulnerabilities are the only private reports accepted. Follow
[SECURITY.md](SECURITY.md) and never include credentials, authorization material, local
databases, firmware payloads, or private device data in a public channel.
